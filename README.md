# Client-Side-Web-security-Threat-analysis-with-policies
An analysis of client-side web security, covering:

1. Client-Side Web Security Analysis
   - Identifying which network entities can observe user activity over
     public WiFi (same-network users, WiFi admin, ISP, intermediate
     servers, website admin)
   - Evaluating VPN anonymity limits
   - Threat modelling for passive network, gadget, and active network attackers
   - Defence-in-depth mitigation strategies

2. Content Security Policy (CSP)
   - Evaluating script execution under a restrictive CSP
   - Designing a CSP that allows only specified resources

3. HTTP Strict Transport Security (HSTS)
   - Using HSTS state as a user-distinguishing side channel
   - How TLS + HSTS Preload defend against redirect/downgrade attacks
